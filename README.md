# Website Security Assessment & Vulnerability Report

## Project Overview

This project demonstrates a web application security assessment performed on OWASP Juice Shop running in a controlled local lab environment.

The assessment included reconnaissance, technology identification, security header analysis, vulnerability scanning, and manual validation.

## Target

OWASP Juice Shop

Environment:
Local Kali Linux Security Lab

## Tools Used

- Kali Linux
- Nmap
- WhatWeb
- cURL
- Nikto
- OWASP ZAP

## Assessment Activities

- Service enumeration
- Web technology fingerprinting
- HTTP security header review
- Web vulnerability scanning
- Security findings validation
- Risk documentation

## Key Findings

- Missing Content Security Policy Header
- Permissive CORS Configuration
- Third-party JavaScript Dependency
- robots.txt Directory Disclosure

## Disclaimer

This assessment was performed against OWASP Juice Shop in a controlled lab environment for educational and portfolio purposes.
